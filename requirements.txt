# SensePi — complete dependency set.
#
# Installing this file gives you a FULLY working app: every tab does everything
# it is meant to do, including Spectrum, Model Updating (OpenSees) and the
# Sonification audio. Nothing here is optional.
#
#     python -m pip install -r requirements.txt
#     python main.py
#
# Use Python 3.12. Python 3.13 and newer install without errors, but on Windows
# the Model Updating tab then fails: the only OpenSees build for them is compiled
# for Python 3.12 (see below). (`main.py` puts `src` on the import path, so a
# separate `pip install -e .` is not required — though it still works.)

# --- GUI, plotting, data ----------------------------------------------------
PySide6>=6.6
pyqtgraph>=0.13
matplotlib>=3.8
numpy>=1.25
scipy>=1.11

# --- Raspberry Pi connection, config, diagnostics ---------------------------
paramiko>=3.3
PyYAML>=6.0
psutil>=5.9

# --- Sonification audio out -------------------------------------------------
# Without this the Sonification tab still draws its panels but stays silent.
sounddevice>=0.4

# --- Model Updating (OpenSees) ----------------------------------------------
# openseespy is a meta-package that pulls the build for your platform. On
# Windows each openseespywin build is compiled for exactly ONE Python version,
# and pip cannot tell: the newest, 3.8.0.0, links python312.dll, so it works on
# Python 3.12 only, yet pip also installs it on 3.13 and 3.14, where the import
# then fails. The lines below give Python 3.12 that build; on Windows + Python
# 3.11 they pick 3.5.1.12, the last build that works there (3.7.0.3, which pip
# would otherwise choose, also links python312.dll).
openseespy>=3.7; sys_platform != "win32" or python_version != "3.11"
openseespy==3.5.1.3; sys_platform == "win32" and python_version == "3.11"
openseespywin==3.5.1.12; sys_platform == "win32" and python_version == "3.11"
opsvis>=1.0
